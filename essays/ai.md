### I. Introduction
AI is seen by some as a powerful tool, while others view it as a way of cheating or as the easy way to the solution. It has certainly helped many students with questions about their classes but is also sometimes wrong. The same is true for its applications within software engineering. AI is very powerful if it always tells you exactly the correct way to write code to work the way you want it to, but often that is not the case. In this essay, I will only comment on ChatGPT as I have no experience with other AI tools.

### II. Personal Experience with AI:
I have used AI in class this semester in the following areas:

  1. Experience WODs e.g. E18 <br />
I never used ChatGPT for the experience WODs mostly because if I didn’t know how to do something I would look at the video instructions when the time was up because I trust the professors to give me the correct way to do something more than AI.
  2. In-class Practice WODs <br />
I also never used ChatGPT in the in-class practice WODs because I felt that it would be a better learning experience for me to try and fail in this environment. Since there was no consequence for me not finishing these WODs I figured that it would be better for me to try and finish these WODs with my knowledge as I would remember better which parts that I struggled on and needed to work on.
  3. In-class WODs <br />
There were certainly times when I could have used ChatGPT in the in-class WODs but chose not to. This was partly because I was being timed and didn’t want to waste my time using incorrect code (if ChatGPT gave me the wrong code) but also I feel like there is value in struggling to find the answer yourself and that it reflects your understanding of the concepts better. So overall I felt like I couldn’t trust ChatGPT and I wanted to prove that I could do it myself without its help.
  4. Essays <br />
I also never used AI when writing any essay because I think it kind of defeats the purpose of writing at all. Why write an essay if none of the words are yours? I also believe that writing essays using AI has become a bit too common and that ways of detecting it are abundant, and being caught can come with very heavy consequences.
  5. Final project <br />
Despite everything I said in the other parts I actually have been using AI a bit in the final project. It is mostly due to MongoDB as I feel I am not very familiar with all the documentation related to it so I have asked ChatGPT questions about what I would use to do certain tasks. For example, I asked it: “im using mongodb and have a collection with the field "wished" and in the publication i want to check if the user ID is in the wished array, how would i do that” and While it gave me code that I couldn’t really use in my project it did correctly tell me that I could use the $in function to see if a user was in the wished array.
  6. Learning a concept / tutorial <br />
I never used AI to help me learn a concept as I don’t trust it to explain it to me thoroughly or completely correctly. I would rather do the class readings or do the experience WODs to gain more understanding of the concepts in the class.
  7. Answering a question in class or in Discord <br />
I never asked or answered a question in Discord so this doesn’t really apply to me. But also I probably wouldn’t use AI for this either because it just seems kind of unnecessary. You shouldn’t need AI to ask a question that you have, and if AI could answer a question that someone posted they (probably) would have asked it already.
  8. Asking or answering a smart-question <br />
Everything I said for “Answering a question in class or in Discord” also applies here but it could be useful to use AI to make sure that your question is “smart” in this case.
  9. Coding example e.g. “give an example of using Underscore .pluck” <br />
I never asked AI to give me an example of it doing code but honestly, I think it could be pretty useful as sometimes it is hard to get examples of certain functions being used. I just never thought of doing this but maybe will in the future.
  10. Explaining code <br />
I have asked ChatGPT to explain not code, but what certain functions do in code or like what they return. For example, I was trying to use “find” in MongoDB but I wasn’t certain if it returned the list of things it found or a true or false telling if it found a match. So I asked ChatGPT “does find return true or false” and it told me it returns a cursor that allows me to iterate through found documents. So I think it is useful in explaining what certain things in code can do.
  11. Writing code <br />
I never asked ChatGPT to write code for me because it is more useful for me to ask about certain things within the code and to write it myself because it actually makes me understand what I'm doing instead of relying on AI to do everything. So I’m sure that you could use AI to write some code for you but I think that for the benefit of my education, I prefer not to use it.
  12. Documenting code <br />
I didn’t use AI to document code mainly because I haven’t documented code recently but also there would probably be no point as after telling it to document the code you would have to go back through it to make sure that it correctly explained how everything works and correct any mistakes that it made. 
  13. Quality assurance  <br />
I have asked ChatGPT to correct code for me in the past but I never really found it useful because instead of telling you exactly where the problem is it would basically just tell me where there were potential problems everywhere within the code, so unless you already knew where the problem was it wouldn’t be very helpful in finding it.
  14. Other uses in ICS 314 not listed above <br />
There are no other uses that I have used AI for that weren’t listed above.

### III. Impact on Learning and Understanding:
I think that AI has had an overall positive impact on my learning experience. As long as I am not using it to solve problems for me without me understanding how to do them then I believe that it is a powerful tool in understanding the material. It is important to also understand that it is not perfect and that you need to know to understand when it is telling you something that isn’t entirely correct. Therefore I believe that it has helped me greatly in software engineering mainly in understanding how certain functions work in structures I am not familiar with such as Meteor and MongoDB.

### IV. Practical Applications:
I think that AI might not be at the level yet where you can entrust it to large tasks to do by itself. You would need people to test the code and debug it which might defeat the purpose in using it in the first place. But as AI advances I am sure that it will be an invaluable tool in real-world coding applications.

### V. Challenges and Opportunities:
One area that I found it hard to use AI in was the in-class WODs mainly because of the time limit. I don’t think it is necessarily a bad thing because I think that the WODs should reflect your own knowledge and that if you choose to use AI then you need to also take the time to debug the code that it writes. 

### VI. Comparative Analysis:
There are certainly benefits to both traditional teaching methods and AI-enhanced learning. In traditional teaching it is much easier to be engaged in the material and learn that way. But with AI many will find it more comfortable to ask targeted questions about specific things that they don’t understand. But with traditional teaching methods you learn more about practical skills because they know how to teach from the fundamentals to more advanced applications.

### VII. Future Considerations:
In the future AI will become a valuable tool for any software engineer in the field. If AI continues to grow as it has in recent years, the day that it becomes smart enough to write code for us with minimal error may be near. I am not certain how AI works right now but if they are able to improve it such that if we were to give them a structure or a sort of pseudocode for it to write and it successfully could do it for us, AI would be very useful.

### VIII. Conclusion:
In conclusion I think that while AI may become a very powerful tool for software engineers in the (possibly near) future that in the current age it is just an okay tool. Right now I feel most comfortable only with asking it to code simple programs for me and to answer questions mainly about how certain functions work. Anything above that I fear that it may give me a solution that doesn’t do exactly what I want or one that may cause me problems in the future. But as AI progresses I will have to open up to the possibilities that it may offer me and be ready to use it in many applications.
