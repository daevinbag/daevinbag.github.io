### Software Engineering, what did I learn?
In software engineering I certainly had many [experiences](https://courses.ics.hawaii.edu/ics314s24/experiences/) and learned a lot about web development. But in this essay I want to talk about the applications of some of the things that I learned in this class beyond the scope of web development and more into applications in future projects / classes.

### Where do I even engineer this software??
Development Environments are definitely going to be useful in applications beyond web development. As the name implies, development environments provide you with a useful environment where you can write and test code. Even before this class I had experience with development environments, where in previous classes when writing code with Java we were advised to use the Eclipse IDE. So that goes to show that although I may not be using IntelliJ, the tool that was used in this software engineering class, I will definitely be using development environments in future classes and probably in applications beyond school. For example, during software engineering, we used IntelliJ to test out our web applications using a local host which proved to be very useful as it allows us to make changes and fix any problems before uploading any final changes to GitHub. This of course can also be a very important thing in not just web applications as it is probably going to be helpful to know before committing your code that it actually works. So development environments allowing you to have a place to debug your code and run many tests is nice. 

### My project has a lot of issues
In software engineering we learned about an agile project management style called issue driven project management. In this type of project management where when working in a group you break down your project into many tasks that are called “issues”. Each member should be working on an issue and the issues should be simple enough that they can be closed in 3 days or less. That is to say, the issues shouldn’t be something really large but should be the steps that lead to the implementation of something larger. The implementation of these issues should have a due date that everything should be done by. 
I think that issue driven project management is one thing that I learned from this class that could end up being very important in the future for me. This is because it is a very efficient way in my opinion to get work done, and to split work among teammates in a group project. Ordinarily I believe such a task would be quite difficult but with a well structured way to manage the project I believe that it becomes quite simple. Of course there always could be problems of people not pulling their weight, but I think with the project board always being updated on GitHub gives everyone a good idea of how much work they have done and if they aren’t pulling their weight, and also gives good insight to people who view the board on who is responsible for what. I think that it is simple to realize how issue driven project management could be useful in applications beyond software engineering as it could be used in many kinds of projects, maybe even outside of coding. And technically it doesn’t even have to be a group project, you could use issue driven project management on a project you are doing by yourself to pace your tasks and visualize how much you need to finish by certain deadlines. Overall I think that it is just a very useful way to visualize large projects and break them down into smaller tasks.

### Thinking Ethically 
I think that questions of ethics will be very important to me going forward because it is something very interesting to think about. What kinds of things do I want to make? What do I want them to do? And most importantly of all, what harm can it cause? These are all questions that I have to consider especially when looking for jobs. I think that it is very important to consider what are the pros and cons of the things that you create, as even if you believe that you are doing the right thing, that it may have major consequences that you are not thinking about. Although I do not have much to offer right now on what the answers to these questions are for me, I’m sure that one day that I will have to think about it, and maybe I’ll update this essay!
